# mnabikhel.github.io
Portfolio — finance, accounting, and AI-directed builds.

## Structure

- `index.html` — portfolio homepage (hero, featured build, work, projects, credentials, contact)
- `northgate.html` — Northgate Constructors case study, including the interactive WIP Mini-Lab
- `styles.css` — shared design system for both pages (no frameworks, no build step)
- `screenshot-*.png`, `excel-*.png`, `headshot.jpg` — images used by the pages
- `Northgate_*.pdf / .xlsx / .pbix` — downloadable case-study files

Fonts (Instrument Sans, Instrument Serif, JetBrains Mono) load from Google Fonts with system fallbacks.
Open `index.html` directly or serve the folder with any static server to preview locally.
